## ⚠️ Do not do these

1. **Never touch board member contact records.** If something needs to change for a board member, tell Jade.
2. **Never merge contacts** without first confirming they're the same person on LinkedIn.
3. **Never create a Salesforce contact without an Account.** Every contact must be attached to a company — and the company must be Active in Salesforce.
4. **Never delete anything.** If something looks wrong, flag it for Aaron or Angela.
5. **Never update Account Status** — that's Shauna's job.
